# Project records

Dated reviews, verification evidence and plans from building Altera, which was called Her until November 2026.
Each describes the app as it was on its date: paths, file names, test counts and open items in them may no longer
be true. For the app as it is now, start with the [user guide](../README.md).

The commit IDs, branch names (such as `codex/password-vault`) and `.worktrees/` folders they mention belong to the
private development history, which is not published. The password vault several of them describe was never finished
and is not part of Altera: the app keeps your data as ordinary files on your PC and can encrypt backups, as
[backup and restore](../BACKUP_AND_RESTORE.md) describes.
